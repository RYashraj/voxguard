# VoxGuard Consent-Based Speaker Verification & Identity Drift Layer

## Overview

The VoxGuard Speaker Verification & Identity Drift Layer (`backend/app/ml/speaker_verification.py`) provides cross-session speaker identity consistency tracking. It compares ongoing call audio chunks against a consented genuine reference voice embedding using a deep ECAPA-TDNN speaker embedding architecture (`speechbrain/spkrec-ecapa-voxceleb`) and cosine similarity scoring.

---

## Strict Privacy & Consent Rules

1. **Explicit User Consent Required**: Reference voice audio MUST be explicitly consented by the caller/user prior to session enrollment.
2. **In-Memory Storage Only**: Reference audio and computed 1D speaker embeddings are stored **ONLY IN MEMORY** inside active `SessionIdentityTracker` instances during active call sessions.
3. **Zero Persistence**: Raw reference audio files and speaker embedding vectors are **NEVER** saved to SQLite databases, disk logs, or external cloud stores.
4. **Immediate Memory Wipe**: Upon session termination or cancellation (`tracker.clear()`), reference embeddings are immediately deleted from memory.

---

## Technical Architecture & Calculation Methodology

### 1. Reference Enrollment
- At session initialization, a consented 16 kHz WAV reference audio sample is passed to `enroll_reference()`.
- The SpeechBrain ECAPA-TDNN classifier encodes the reference waveform into a 192-dimensional embedding vector $v_{\text{ref}}$.
- The raw reference audio buffer is discarded, leaving only $v_{\text{ref}}$ in memory.

### 2. Chunk Verification & Cosine Similarity
- For each incoming call audio chunk, the model encodes a chunk embedding vector $v_{\text{chunk}}$.
- Cosine similarity is calculated as:
  $$\text{CosineSim}(v_{\text{ref}}, v_{\text{chunk}}) = \frac{v_{\text{ref}} \cdot v_{\text{chunk}}}{\|v_{\text{ref}}\| \|v_{\text{chunk}}\|}$$
- Cosine similarity is mapped to normalized speaker similarity:
  $$\text{speaker\_similarity} = \max\left(0.0, \min\left(1.0, \frac{\text{CosineSim} + 1}{2}\right)\right)$$
- Identity drift is derived as:
  $$\text{identity\_drift} = 1.0 - \text{speaker\_similarity}$$

### 3. Reason Codes and Flags

| Status Code | Description | User/UI Flag |
| :--- | :--- | :--- |
| `ok` | Speaker embedding successfully computed and compared. | `identity_mismatch` (if `identity_drift > 0.45`) |
| `reference_unavailable` | No reference audio was enrolled for the active session. | `reference_unavailable` |
| `insufficient_speech` | Chunk duration < 0.5s or contains insufficient voiced frames. | `insufficient_speech` |
| `silent_audio` | Chunk RMS energy < 0.001. | `silent_audio` |
| `identity_unavailable` | SpeechBrain dependency or model weights unavailable. | `identity_unavailable` |

## Critical System Disclaimers

### Spoof Detection vs. Speaker Verification

| Metric | Core Model | Question Answered |
| :--- | :--- | :--- |
| **Acoustic Anti-Spoofing** | Spectra-AASIST3 (`chunk_score`) | *"Is this voice signal generated by an AI model/cloner or a real human mouth?"* |
| **Speaker Verification** | SpeechBrain ECAPA-TDNN (`identity_drift`) | *"Does this voice signal match the enrolled reference identity for this call session?"* |

### Why Speaker Mismatch Does NOT Prove AI Cloning
1. **Legitimate Speaker Swaps**: A call handoff, co-caller, or background speaker intervention produces a high identity drift (speaker mismatch), even though both speakers are live humans.
2. **Channel & Mic Variation**: Switching from a speakerphone to a headset or changing network codecs can alter spectral color, increasing identity drift.
3. **Independent Signals**: Speaker identity drift is a security context signal. AI deepfake detection requires Spectra-AASIST3 acoustic classification.

---

## Limitations on Short Telephony Audio
- **Chunk Windowing**: 3-second streaming chunks contain limited phonetic variability compared to full 10-second enrollment phrases.
- **Noise & Codecs**: Telephony codecs (e.g., AMR-WB, G.711) and background noise degrade embedding alignment, requiring safe fallback status (`insufficient_speech`).
